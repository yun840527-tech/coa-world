      구글 시트 연동
      Apps Script 웹 앱 주소와 PIN을 넣으면 업무 지시가 시트로 오갑니다.

      URL·PIN은 이 브라우저(localStorage)에만 저장되고 공개 페이지에는 들어가지 않아요. 구글 계정 권한은 건드리지 않습니다.

      처음이면 · 1분 설정 순서
      1. 구글 시트를 열고 확장 프로그램 → Apps Script.
      2. Code.gs 전체를 붙여넣고, 맨 위 PIN 을 내 번호로 바꾼 뒤 저장.
      3. 배포 → 새 배포 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → 나온 …/exec 주소 복사.
      4. 위 칸에 주소와 PIN 을 넣고 연결 테스트 → 저장하고 연결.
